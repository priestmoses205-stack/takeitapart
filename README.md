# God Eye Dimension

Hand-controlled 3D particle models in the browser. Snap, point, pinch and pull apart anatomy, engines, landmarks and machines.

Live: https://priestmoses205-stack.github.io/takeitapart/

- WebGL2 point-sprite engine, no framework
- MediaPipe HandLandmarker (21 landmarks, on-device)
- 8 models, 238,730 particles
- Everything also works with mouse and keyboard

Built by Ghost / God Eye.
